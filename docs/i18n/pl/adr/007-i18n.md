# 007. Wielojęzyczny interfejs, język wprowadzania i architektura RTL

Data: 2026-11-21
Status: Zaakceptowano (zatwierdzono 29 języków, podział Wyjście/Wejście i przypinanie w Profilu)

## Kontekst

ExoNovel służy pisarzom i czytelnikom na całym świecie na **Web, Linux, macOS, Windows, Android i iOS**. Użytkownik może korzystać z menu aplikacji w jednym języku, pisząc rękopis lub czatując w innym—w tym w mieszanych skryptach **RTL i LTR** bez powiększania paczki WebAssembly.

## Decyzja

### 1. Dwa rozdzielne wymiary języka: Wyjście (UI) vs Wejście (Tworzenie i Czat)
1. **Język interfejsu (`ui_locale`)**: Kontroluje całe menu, przyciski, Preferencje, Profil i powiadomienia poprzez `user_profiles.ui_locale` oraz `<html lang="..." dir="...">`.
2. **Język treści (`default_input_locale` + przełącznik w polu edycji)**: Kontroluje język rozdziałów, notatek i wiadomości niezależnie od języka UI, ustawiając HTML `lang`/`dir` oraz podpowiedzi sprawdzania pisowni i IME.

### 2. Ładowanie na żądanie, pakiety offline i przełącznik z flagą przed nazwą
- **Web**: Serwerowy preload + buforowany `/api/i18n/{locale}` w Mozilla Fluent (`.ftl`), dzięki czemu nieużywane języki nie powiększają pakietu WASM.
- **Natywne pakiety offline**: Pobieranie dodatkowych pakietów `.ftl` z publicznej przestrzeni **`willow25` / `iroh-blobs`**.
- **Przełącznik w stylu GitHub z flagą przed nazwą**: Przełącznik języka w górnym pasku wyświetla wbudowaną flagę SVG **przed** nazwą własną języka (`[Flaga] Polski`, `[Flaga] Deutsch`, `[Flaga] English`). W Profilu można przypinać ulubione języki szybkiego przełączania.

### 3. Katalog startowy (29 języków)
- **Europa**: `en`, `de`, `pl`, `fr`, `es`, `it`, `nl`, `pt`, `hu`, `ro`, `uk`, `ru`, `sr`, `el`.
- **RTL**: `ar` (arabski), `he` (hebrajski) z pełnym lustrzanym układem logicznym CSS (`ms-*`, `me-*`, `ps-*`, `pe-*`).
- **Azja Wschodnia i Południowa**: `zh-Hans`, `zh-Hant`, `hi`, `bn`, `mr`, `te`, `ta`.
- **Afryka**: `sw`, `ha`, `yo`, `ig`, `am`, `zu` (obok `ar`, `fr`, `en`, `pt`).

### 4. Zsynchronizowana dokumentacja wielojęzyczna (`adr_translations`)
- Zgodnie z `AGENTS.md` Regułą 18 wszystkie aktywne wydania językowe dokumentacji (`en`, `de`, `pl`) utrzymywane są synchronicznie.
- W Neon PostgreSQL tabela `adr_translations` (`UNIQUE(adr_id, locale)`) przechowuje tłumaczenia poszczególnych ADR i automatycznie wraca do wersji angielskiej przy braku tłumaczenia.
